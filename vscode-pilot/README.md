# Pilot Language Support for Visual Studio Code

Official VS Code extension for the **Pilot** programming language.

## Features

What works and what does not (2026-11-18):

- **Syntax highlighting: works.** A TextMate grammar for Pilot keywords, operators, strings, comments and types (`syntaxes/`), generated by `selfhost/ide/vscode_gen.pilot`.
- **Language server (LSP): not working.** The extension starts a `pilot-lsp` executable if one is on the path or configured, and otherwise runs `pilot lsp`. There is no `pilot-lsp` program in this repository, and `pilot lsp` stops at seam `cli.command_handler` (no handler is registered). So diagnostics, hover, completion, inlay hints and go-to-definition do not work from a source checkout.
- **Debugger (DAP): not working.** Same situation: there is no `pilot-dap` program, and `pilot debug` stops at seam `cli.command_handler`.
- **Run and test commands:** the editor commands call the `pilot` CLI (`pilot run`, `pilot test`), so they work when `pilot` is on the path.

## Quick Start

1. Install the `.vsix` extension package into VS Code.
2. Open any `.pilot` file.
3. Press `F5` to debug, or click the **Run** / **Debug** icons in the top-right of the editor title bar.
