# Pilot Language Support for Visual Studio Code

Official VS Code extension for the **Pilot** programming language.

## Features

What works and what does not (2026-11-18):

- **Syntax highlighting: works.** A TextMate grammar for Pilot keywords, operators, strings, comments and types (`syntaxes/`), generated by `selfhost/ide/vscode_gen.pilot`.
- **Language server (LSP): works, in Pilot.** The extension runs `pilot lsp` with the newest `pilot` it finds (`target/release`, `target/debug`, then the path), unless `pilot.languageServer.serverPath` names another server. Everything it reports comes from Pilot's type checker (`selfhost/lsp/`): diagnostics after typing pauses for 300 ms and on open and save (unsaved text included), hover (type, signature and `///` doc comment) and go-to-definition. No completion, references or rename yet. A file under `stdlib/` gets hover and definition but no checker diagnostics, as with `pilot check`.
- **Debugger (DAP): runs the program, no debugging.** Starting a debug session runs the file with the current `pilot run` and shows its output in the Debug Console. Breakpoints are reported unverified and there is no stepping: `pilot debug` stops at seam `cli.command_handler`, and the VM has no hooks to pause at a line. A `pilot.dap.serverPath` setting, when set, is used instead.
- **Run and test commands:** the editor commands call the `pilot` CLI (`pilot run`, `pilot test`), so they work when `pilot` is on the path.

## Quick Start

1. Install the `.vsix` extension package into VS Code.
2. Open any `.pilot` file.
3. Press `F5` to debug, or click the **Run** / **Debug** icons in the top-right of the editor title bar.
