# `pilot.md` — Canonical Map of Pilot Implementations & Language-First Responsibilities

> **Governance Mandate ([`AGENTS.md`](file:///home/moony/Documents/dev/projects/Pilot/AGENTS.md) §1):**
> 1. **Pilot First (`<= 1,500` LOC Law):** Every language feature, keyword, syntax rule, memory/arena/Perceus mechanism, compiler pass, target emitter, foreign adapter, transport DOM, and CLI/IDE tool representable in `<= 1,500` LOC per file lives in Pilot—**never in Rust**.
> 2. **Airlock Freeze and One Op, One Owner (Model B+, `PROP-002a` + Amendment A1):** `stdlib/core/bridge_lang.pilot`, `stdlib/core/os_abi.pilot` and `crates/pilot-vm/src/bridge.rs` are frozen under B+ via [`proposals.md`](file:///home/moony/Documents/dev/projects/Pilot/proposals.md): frozen items are never deleted, renumbered or redefined, and additions are append-only. Each runtime engine op appears once, as the body of one `[EngineOp] priv static fn ..._internal` on its owner type (`stdlib/core/host_raw.pilot`, `file.pilot`, `env.pilot`), called only by its public method (enforced by `GATE021` + `selfhost/gate/airlock_abi.pilot`). Zero other `.pilot` files may introduce `__engine(...)` (`ENGINE001`).
> 3. **Delete Dead & Legacy Code Immediately:** Whenever dead or superseded Pilot code is encountered, delete it on the spot before moving on and update this map in the same change.
> 4. **Anti-Duplication & Matrix Sync:** Check this map, [`rust.md`](file:///home/moony/Documents/dev/projects/Pilot/rust.md), [`docs/keyword_matrix.md`](file:///home/moony/Documents/dev/projects/Pilot/docs/keyword_matrix.md), and [`docs/concept_matrix.md`](file:///home/moony/Documents/dev/projects/Pilot/docs/concept_matrix.md) before writing code so no type, helper, or pass is ever duplicated.
> 5. **Break Loud With `seam(...)` During Contraction:** Breaking `.pilot` files when deleting misplaced Rust is expected and welcome—denote every broken or not-yet-rebuilt Pilot path loudly with `seam("<area>.<what>", "<reason>")` (`SEAM001`, registered in `seams.pilot`) instead of falling back to Rust.
